# 10 - AI Context

Estas reglas deben seguirse siempre.

- No generar código duplicado.
- Pensar antes de programar.
- Proponer arquitectura antes de implementar.
- Mantener módulos desacoplados.
- Aplicar SOLID, DRY, KISS y YAGNI.
- TypeScript strict.
- No usar any.
- Validar toda entrada.
- Documentar decisiones importantes.
- Crear componentes reutilizables.
- Nunca romper compatibilidad del MVP.
- Priorizar claridad sobre complejidad.
- Si una funcionalidad puede crecer, diseñar interfaces para extenderla.
- Generar código listo para producción.
