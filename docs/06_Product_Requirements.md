# 06 - Product Requirements (PRD)

## Objetivo
Construir un MVP de eCommerce + gestión de inventario para una joyería, preparado para escalar.

## Módulos MVP
- Autenticación
- Dashboard
- Catálogo
- Productos
- Categorías
- Inventario
- Movimientos de stock
- Ventas
- Carrito
- Checkout
- Usuarios y roles
- Configuración

## Requisitos funcionales

### Productos
- Crear, editar, archivar productos.
- Código automático legible (ej. AN-PL-000001).
- Múltiples imágenes.
- Precio contado.
- Precio lista.
- Cálculo de ahorro por transferencia.
- Material.
- Categoría.
- Subcategoría.
- Etiquetas.
- Estado.

### Inventario
- Stock por sucursal.
- Nunca editar stock manualmente: generar movimiento.
- Tipos: ingreso, venta, ajuste, transferencia.

### Ventas
- Carrito.
- Checkout.
- Mercado Pago.
- Transferencia.
- Efectivo.
- Reserva de stock.
- Confirmación.

### Dashboard
- Ventas del día.
- Ventas del mes.
- Productos sin stock.
- Productos críticos.
- Ingresos.
- Egresos.
- Ticket promedio.

### Roles
Administrador, Empleado y Contador con permisos independientes.

## Requisitos no funcionales
- Responsive.
- Tiempo de carga <2 s.
- Accesibilidad básica.
- Auditoría de acciones.
- Escalable.
